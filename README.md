# The Tech Encyclopedia

One big, searchable page about tech: computer parts, laptops, phones, brands, cables, software, the internet, security, AI, home labs, VoIP, business tech, vintage and gimmicky gadgets, and more.

- **Read it online:** https://abudahoom.github.io/techencyclopedia/
- **PDF version:** [tech-encyclopedia.pdf](tech-encyclopedia.pdf)

**Site features:** search with typo tolerance, 🎲 random entry, ⭐ bookmarks (saved in your browser), ⬇ PDF download, Arabic interface (ع button), dark mode, and offline use: on a phone, choose *Add to Home Screen* to install it like an app.

Photos are hot-linked from Wikimedia Commons, with a credit link under each one.
